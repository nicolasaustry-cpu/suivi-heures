Cases à cocher

Choisir le type de poste

  • Poste administratif — sans horaires à vendre, avec accès à la vue équipe sur mobile ; permet aussi de saisir de nouveaux chantiers et des RDV depuis le mobile.
  • Ce salarié alterne deux semaines (A / B) — pour une semaine haute et une semaine basse (ex. un vendredi sur deux).
  • Apprenti / alternant (périodes d'école) — permet de saisir les semaines d'école.

Colonne PIN

Codes PIN d'accès

Le PIN est le code d'accès personnel du salarié sur l'appli mobile.

  • Le cadenas verrouille le code, l'œil l'affiche, Réinit. le réinitialise.
  • Terminez par Enregistrer les PIN. Le bouton Salariés présents donne la liste des présents.
🔒 Enregistrer les PIN ✔ Salariés présents ↺ Réinit.
