Obtenir vos clés de production Henrri

7 étapes pour générer, dans votre compte Henrri, les identifiants qui permettent à Suiv'Heures de récupérer vos devis validés et votre base clients.

⏱ ≈ 10 min (hors délai de traitement) 🧩 Aucun code requis

Ce que vous aurez à la fin

  • 🔑 Client IDIdentifiant de la clé, toujours consultable.
  • 🛡️ Client SecretAffiché une seule fois : à sauvegarder aussitôt.
  • ✅ Droits ouvertsSans eux, la clé ne donne accès à rien.

1

Remplissez le formulaire de demande

L'accès en production doit être demandé à Henrri via un formulaire.

📍 Où : www.henrri.net → cliquez sur votre avatar → API & Intégrations → section Clé de production
Ouvrir le formulaire de demande ↗
Dans la description de l'usage prévu, indiquez Suiv'Heures suivi du nom de votre entreprise, par exemple : « Suiv'Heures – SARL Dupont Bâtiment ».
2

Attendez le mail de confirmation d'Henrri

L'ouverture n'est pas automatique : Henrri traite la demande puis vous envoie un e-mail de confirmation. C'est ce mail qui fait foi, aucune notification n'apparaît dans l'interface.

Une fois l'accès ouvert, le bouton + NOUVELLE CLÉ apparaît dans la section Clé de production.

⚠ Les comptes Henrri provisoires ne peuvent pas obtenir de clé de production.
3

Cliquez sur « + NOUVELLE CLÉ »

📍 Où : API & Intégrations → section Clé de production → + NOUVELLE CLÉ

Un réglage permet de restreindre l'accès à certaines adresses IP. Par défaut, toutes les adresses sont autorisées.

⚠ Pour une utilisation avec Suiv'Heures, laissez toutes les adresses IP autorisées : les appels partent des serveurs de Suiv'Heures, pas de votre ordinateur. Une restriction sur l'adresse de votre bureau bloquerait la connexion.

Le nombre d'appels autorisés par minute dépend de votre formule Henrri (de 60 à 600 par minute) ; il est largement suffisant pour Suiv'Heures.

4

Acceptez l'engagement de responsabilité

Une fenêtre s'ouvre avec les conditions : confidentialité, sécurité, usage conforme, responsabilité sur les données, et un cadre déroulant Conditions d'activation.

🛑 Le point qui bloque le plus souvent : le bouton GÉNÉRER MA CLÉ DE PRODUCTION reste grisé tant que vous n'avez pas fait défiler le cadre des conditions jusqu'en bas.

Complétez ensuite le formulaire :

  • E-mail (obligatoire)
  • Téléphone (obligatoire)
  • Description de l'usage prévu (obligatoire) : Suiv'Heures suivi du nom de votre entreprise
  • les deux cases à cocher
Une clé ne vaut que pour un seul compte Henrri : celui de votre entreprise.
5

Donnez un nom à votre clé

Le navigateur vous demande un nom pour la clé. Nommez-la d'après son usage plutôt que d'après sa date, pour la reconnaître facilement plus tard.

✔ Exemple : Suiv'Heures plutôt que « clé 2 ».
6

Sauvegardez immédiatement votre Client Secret

La fenêtre SAUVEGARDEZ VOTRE SECRET API HENRRI affiche votre secret. Trois boutons :

  • 📋 COPIER : pour le coller dans un gestionnaire de mots de passe ;
  • ⬇ TÉLÉCHARGER : pour l'enregistrer dans un fichier texte, à ranger en lieu sûr ;
  • ✓ C'EST NOTÉ : ferme la fenêtre.
🛑 Le secret ne sera plus jamais affiché. S'il est perdu, il faut régénérer la clé (icône de rafraîchissement) et ressaisir le nouveau secret partout où il est utilisé. Ne l'envoyez jamais par e-mail ni dans une conversation.
7

Ouvrez les droits de la clé

Après C'EST NOTÉ, la fiche de la clé affiche le Client ID (toujours consultable).

🛑 Une clé neuve n'a aucun droit. La fiche indique « Accès 0 en lecture, 0 en écriture · Aucun scope actif ». Tant que vous ne les ouvrez pas avec MODIFIER, la connexion sera refusée.

Cliquez sur MODIFIER et n'ouvrez que ce dont Suiv'Heures a besoin, en lecture uniquement :

  • Clients : lecture (base clients, coordonnées des chantiers)
  • Documents : lecture (devis validés vers le Prévisionnel)

Aucun droit en écriture n'est nécessaire : Suiv'Heures ne modifie rien dans votre compte Henrri.

Et maintenant : saisissez vos clés dans Suiv'Heures

  1. Ouvrez la page Entreprise, tuile Connexion Henrri.
  2. Cochez Connecté à Henrri et choisissez l'environnement Production.
  3. Collez votre Client ID et votre Client Secret.
  4. Cliquez sur Enregistrer.
