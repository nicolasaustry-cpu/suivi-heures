L'export des devis validés Henrri ne contient pas les coordonnées des clients : l'import se fait donc avec deux fichiers. ① La liste des clients Henrri (coordonnées), puis ② les devis validés (n° de devis, nom prénom, nombre d'heures et nombre d'heures analysées). Suiv'Heures rattache ensuite chaque devis à ses coordonnées : en priorité celles déjà présentes dans vos fiches chantier, sinon celles de la liste clients importée. Les devis sont ensuite proposés dans le bouton « Devis Henrri » du Prévisionnel, pour être affectés à un mois.

1 Fichiers Henrri

① Liste des clients Henrri

Export de votre base clients depuis Henrri : nom, adresse, code postal, ville, téléphones, e-mail.

Déposez le fichier clients ou cliquez pour le choisir — Excel ou CSV

② Devis validés

Export des devis validés depuis Henrri : n° de devis, nom prénom, nombre d'heures, nombre d'heures analysées.

Déposez le fichier des devis ou cliquez pour le choisir — Excel ou CSV

2 Correspondance des colonnes

Les colonnes ont été reconnues automatiquement. Corrigez-les si nécessaire. * = obligatoire. Le code client, s'il figure dans les deux fichiers, rend le rattachement plus sûr qu'avec le seul nom.
